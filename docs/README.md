## Цель продукта

Приложение помогает выбрать героя во время драфта Dota 2. Основной сценарий пользователя — рейтинговая игра с открытым приложением на телефоне.

Пользователь вводит союзников, противников и баны. Приложение показывает до пяти рекомендаций для каждой позиции. Рекомендации пересчитываются после изменения драфта.

Цель — улучшить выбор героя. Гарантия победы и доказанный прирост винрейта отсутствуют.

## Принятые решения

- React, TypeScript и Vite. Статический сайт на GitHub Pages.
- Данные находятся в JSON внутри репозитория. Обновление выполняется вручную.
- Нет сервера, базы данных, регистрации и вызовов LLM.
- Нет начального выбора ранга или позиции пользователя. Приложение оценивает все пять позиций.
- Союзные слоты соответствуют позициям 1–5. Все слоты доступны для изменения.
- Позиции противников неизвестны. Номер вражеского слота не обозначает его роль.
- На телефоне рекомендации переключаются табами позиций.
- Интерфейс остаётся минимальным. Карточка рекомендации содержит номер, изображение и имя героя.
- Пул героев и обратная связь после матча отложены. Они не входят в текущий MVP.

Последнее решение о рекомендациях для всех позиций заменяет прежний сценарий с выбором одной роли.
